# B 端产品文案 · 初稿

> 基准设定：示例产品为「企业自助式数据分析平台」。你的产品若是其他品类，只改文末「换品指南」列出的 4 处词槽，其余结构和话术直接复用。

## 一、核心定位

**一句话公式：**
[产品名] 是面向 [目标客户] 的 [品类]，[核心差异点]，帮 [角色] 把 [旧做法] 从 [旧成本] 降到 [新成本]。

**示例填法：**
「XX 是面向中大型企业的自助式数据分析平台，业务人员不写 SQL 就能自己出报表，把报表交付周期从一周压到十分钟。」

**电梯稿（销售开场 30 秒版）：**
「很多公司报表慢，不是数据不够，是所有取数都堆在 IT 排期上。XX 把分析能力直接给到业务：拖拽建看板，口径全公司统一，IT 只需要管好数据和权限。上线一周内就能看到第一张业务看板。」

## 二、官网首页

### Hero 区

**主标语（三选一）：**
1. 让业务决策，回到数据本身 —— 稳重，适合官网首屏
2. 别再等 IT 排期了，业务自己就能查数 —— 直给，适合投放落地页
3. 把数据，变成全公司都会用的答案 —— 亲和，适合品牌物料

**副标语：** 无需 SQL，5 分钟接入业务系统。市场、销售、运营自助出数，口径全公司统一。

**CTA：** 主按钮「预约演示」｜次按钮「免费试用 14 天，无需绑卡」

### 价值主张（三列，痛点 → 能力 → 证据）

**1. 业务自助，不等排期**
拖拽式分析，销售漏斗、库存周转、活动 ROI 当场出数。
证据位：报表平均交付周期 7 天 → 10 分钟。

**2. 一个指标，一个口径**
指标中心统一管理定义，财务、业务、老板看到的是同一个数。
证据位：跨部门口径争议减少 80%。

**3. 企业级安全，数据不出内网**
支持私有化部署、行级列级权限、全量审计日志。
证据位：已通过等保三级 / ISO 27001 认证。

### 功能模块（标题 + 一句人话 + 支撑点）

- **数据接入**：50+ 连接器。数据库、Excel、业务系统 API 一次接通，支持增量同步。
- **可视化看板**：30+ 图表组件。拖拽出图，大屏、移动端自适应。
- **指标中心**：一个指标一处定义。全局复用，改口径一次生效。
- **权限与审计**：细到行和列。谁看过、看过什么，全程留痕。
- **智能告警**：异动主动找人。阈值触发后微信 / 钉钉 / 邮件直达。

### 信任背书区

「已服务 300+ 中大型企业 · 覆盖金融、制造、零售」
案例标题模板：[客户名] 用 XX 把月度经营分析从 3 天压到 2 小时

### 页尾 CTA

「现在预约，30 分钟看到你自己的数据变成看板。」

## 三、场景变体

**投放落地页（短版）：**
标题：还在用 Excel 拼月报？
正文：接上数据源，拖拽建看板，全公司一套口径。14 天免费试用，无需绑卡。
CTA：免费开始

**公众号 / 知乎长文开头（钩子）：**
每月一号，数据组的群里都在互相 @：「销售口径的 GMV，到底包不包含退款？」
这个月已经是第三次了。真正的问题不是谁算错了，而是——全公司没有一个统一口径的地方。

**招聘 / 社媒（活泼变体，仅限此处使用）：**
「在这里，你写的每一行代码，都会变成某家公司周会上的一个数字。」

## 四、语气基调（定稿）

- **主基调**：专业、克制、结果导向。说人话，让数字说话，形容词最少化。
- **禁用词**：赋能、抓手、闭环、颠覆、极致（引用客户原话除外）。
- **版式节奏**：每个模块 = 标题（≤10 字）+ 一句人话（≤20 字）+ 一个证据（数字 / 认证 / 客户名）。

## 五、换品指南（改成你的产品只动这 4 处）

1. 品类词：「自助式数据分析平台」→ 你的品类
2. 痛点场景：「等 IT 排期出报表」→ 你的核心痛点
3. 角色词：「业务 / IT」→ 你的买方与使用者
4. 证据位：等保三级、300+ 客户 → 你的真实资质与客户数

> ⚠️ 文中所有证据位（数字、认证、客户名）均为占位示例，上线前必须替换为可验证的真实数据。
