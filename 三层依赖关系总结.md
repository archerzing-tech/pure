## 核心设计原则

| 原则 | 说明 |
|:-----|:-----|
| **运行时无关** | 核心引擎 (Layer 2/3) 纯 TypeScript，不依赖任何特定运行时 |
| **Adapter 隔离** | 所有外部依赖（LLM、存储、MCP）通过 Adapter 抽象 |
| **流式产出** | Engine 通过 AsyncGenerator yield 分步产出事件，不阻塞 UI |
| **检查点持久化** | Harness 在关键节点保存完整状态检查点，会话可恢复 |
| **软预算限制** | Budget 耗尽先警告后终止，提供宽限期 |
| **MCP 优先** | 工具扩展优先通过 MCP 协议，而非硬编码固定工具分类 |
| **可测试** | 每层可独立 Mock 测试，Engine 为纯函数 |

## 跨文档一致性说明

> **统一组件定义说明**：
> - **EventBus**：核心实现在 **Shared Kernel**，`Harness` 通过 `declaration merging` 扩展事件类型，
>   `Coding Agent` 也通过同样机制扩展。所有层引用同一份基础实现。
> - **Verifier**：接口定义在 **Shared Kernel** (`VerifierAdapter`)，**Engine** 依赖该接口，
>   **Coding Agent** 中的 `Verifier` 类是实现，通过 `HarnessConfig` 注入给 **Harness** 使用。

| 组件 | 定义位置 | 实现位置 | 引用方 |
|:-----|:---------|:---------|:-------|
| **EventBus** | Shared Kernel（基础实现） | 同左 | 所有层通过 declaration merging 扩展 |
| **VerifierAdapter** | Shared Kernel（接口） | Coding Agent（Verifier 类） | Engine（依赖接口）+ Harness（通过 Config 注入） |
| **状态管理** | StateManager（检查点持久化） | Harness 层 | Coding Agent 引用 |
| **上下文压缩** | ContextEngine（滑动窗口+摘要 fallback） | Harness 层 | Coding Agent 引用 |
| **流式输出** | StreamManager（事件合并） | Harness 层 | Coding Agent 引用 |
| **MCP** | MCPClient（发现+调用） | Harness 层 | Coding Agent 引用 |
| **文件监听** | FileWatcher（chokidar） | Harness 层 | Coding Agent 引用 |
| **Subagent** | SubagentRegistry（超时+级联中断） | Harness 层 | Coding Agent 引用 |

> **注**：新版 `StateManager` 采用检查点机制，在关键 turn 边界保存完整状态。
> 不再维护旧版的细粒度版本链，也不提供任意版本回滚能力。
